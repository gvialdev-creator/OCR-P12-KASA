Methods

(async, inner) createProperty()

Crée un logement, génère son slug unique et insère ses listes associées. Le contrôleur HTTP doit fournir l’hôte issu de l’identité authentifiée; cette fonction de service accepte également un host_id ou un objet host. Un prix absent/non positif retombe actuellement à 80; un code postal non nul doit contenir cinq chiffres. L’opération complète n’est pas transactionnelle.
