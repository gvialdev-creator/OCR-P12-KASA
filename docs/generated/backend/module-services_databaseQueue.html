(inner) transaction(db, operation) → {Promise.<unknown>}

Exécute une opération SQLite atomique sur la connexion partagée. Les opérations sont sérialisées par connexion ; les appels imbriqués dans l’opération courante réutilisent son contexte. En cas d’échec, la transaction est annulée puis l’erreur d’origine est propagée.
